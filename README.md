# GigaAM Simple

Простое приложение для Windows, которое превращает аудиофайлы с русской речью в текст на вашем компьютере. Использует открытые модели [GigaAM v3](https://github.com/salute-developers/GigaAM) и локальный детектор речи [Silero VAD](https://github.com/snakers4/silero-vad).

Это тестовая версия с интерфейсом на Tkinter. Распознавание работает на процессоре, без подписки, ключей API и облачной отправки записи. Интернет нужен для первоначальной установки и скачивания моделей.

## Возможности

- MP3, WAV, M4A, OGG, FLAC и другие форматы через FFmpeg.
- Длинные записи: определение речи и пауз, фрагменты до 24 секунд.
- Таймкоды относительно начала исходного аудио.
- Две вкладки: исходный текст и очищенный текст с возможностью правок.
- Осторожная очистка заминок, заиканий и отдельных «угу», «ага», «мгм». Удаление коротких реплик можно отключить.
- Прослушивание фрагмента по нажатию на таймкод.
- Повторное распознавание выбранного фрагмента другой моделью.
- Открытие готового TXT и сохранение двух версий.
- Отмена обработки с сохранением завершённых фрагментов в окне.

## Установка

Нужны **Windows**, **Python 3.12 (64 бит)** с Tkinter и **Git**. Проверенная конфигурация использует CPU-версии PyTorch и torchaudio 2.6.0. Приложение не требует видеокарты NVIDIA.

1. Установите [Python 3.12](https://www.python.org/downloads/windows/). В установщике включите добавление Python в PATH и компонент Tcl/Tk.
2. Установите [Git для Windows](https://git-scm.com/downloads/win).
3. Скачайте этот репозиторий через **Code > Download ZIP** и распакуйте его или клонируйте:

   ```powershell
   git clone https://github.com/logser13/gigaam-simple.git
   cd gigaam-simple
   ```

4. Дважды нажмите **Start.cmd**. При первом запуске он создаст `.venv`, скачает проверенную ревизию GigaAM, установит зависимости, подготовит FFmpeg и загрузит основную модель CTC.

Для первоначальной установки нужен интернет и свободное место под зависимости и модели. Веса основной модели занимают примерно 422 МБ. Файлы сохраняются в `models/` и не включены в GitHub-репозиторий.

Если автоматическая подготовка не завершилась, можно запустить её вручную из папки проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

## Использование

1. Нажмите **Выбрать аудиофайл**, затем **Распознать**.
2. Сравните вкладки **Исходный** и **Очищенный**. Очищенный текст можно редактировать.
3. Нажмите на синий таймкод, чтобы прослушать соответствующий фрагмент.
4. При необходимости выберите другую модель и нажмите **Распознать фрагмент**. Ручные правки в других фрагментах сохраняются. Пустой результат повтора не стирает прежний текст.
5. Нажмите **Сохранить обе версии**.

Сохраняются выбранный очищенный TXT и отдельная исходная копия с суффиксом `.original.txt`. Повторное сохранение создаёт `.original-2.txt` и далее, не перезаписывая прежние исходные копии. Очистка сохраняет числа, имена, «да», «нет» и отрицания; она не восстанавливает испорченные слова по догадке.

**Открыть TXT** позволяет очистить уже готовый текст. Для прослушивания TXT с таймкодами дополнительно выберите соответствующий исходный аудиофайл. Новые таймкоды для обычного TXT без времени не создаются.

## Две модели

| В интерфейсе | Модель | Подготовка |
| --- | --- | --- |
| Обычная | `v3_e2e_ctc` | Скачивается при первом запуске |
| Альтернативная | `v3_e2e_rnnt` | Запустите `Prepare-alternative.cmd` один раз с интернетом |

RNNT может давать другой и более читаемый результат на отдельных записях, но не гарантирует улучшение. Обе модели работают локально. После скачивания переключение модели не требует интернета.

## Ограничения

- Приложение рассчитано на Windows: прослушивание использует `winsound`.
- Это исходники с запуском через Python, отдельного установщика EXE пока нет.
- Имена, числа, отрицания и иностранные термины могут распознаваться ошибочно. Их нужно сверять с записью.
- Таймкоды относятся к аудиофрагментам, а не к каждому слову или смене говорящего.
- Детектор иногда пропускает очень тихую или короткую речь. При непрерывной речи без пауз возможен разрез внутри слова.
- Очистка коротких реплик может убрать ответ собеседника. Он остаётся в исходной версии; флажок очистки можно отключить.
- Разделения говорящих и автоматического пересказа нет.
- Скорость зависит от процессора и записи. Приложение не сохраняет несохранённые результаты между запусками.

## Локальные данные

Исходное аудио не изменяется. Временные WAV удаляются после завершения обработки, отмены или обычной ошибки. Исходники приложения не содержат телеметрии или отправки аудио и текста. Ошибки записываются в локальный `app.log`.

Записи, транскрипты, логи, окружение Python, сторонние исходники и скачанные модели исключены через `.gitignore`.

## Проверки

После установки:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s . -p "test_*.py"
.\.venv\Scripts\python.exe check_ui.py
.\.venv\Scripts\python.exe check_review_ui.py
```

Тесты проверяют сохранность аудиофрагментов и таймкодов, очистку текста, отдельное сохранение исходной версии, отмену, повторную обработку и работу интерфейса. Они не измеряют точность модели по эталонной расшифровке. Проверка `check_review_ui.py` использует короткий беззвучный WAV и Windows API воспроизведения.

Для запуска модульных тестов без скачивания GigaAM достаточно Python 3.12 с Tkinter и пакета `imageio-ffmpeg==0.6.0`.
