# GigaAM Simple

Простое приложение для Windows, которое превращает аудиофайлы с русской речью в текст на вашем компьютере. Использует открытые модели [GigaAM v3](https://github.com/salute-developers/GigaAM) и локальный детектор речи [Silero VAD](https://github.com/snakers4/silero-vad).

Это тестовая версия с интерфейсом на Tkinter. **После первоначальной установки приложение работает полностью локально, без интернета.** Распознавание работает на процессоре, без подписки, ключей API и облачной отправки записи. Интернет нужен только для установки зависимостей и первоначального скачивания моделей.

**По умолчанию выбрана модель GigaAM v3 E2E RNNT («Альтернативная»).** Она в среднем точнее распознаёт русскую речь. Если важнее скорость, в поле «Модель» можно выбрать «Обычную» CTC.

**В этой версии можно разделять разговор по спикерам и сохранять текст с таймкодами или без них.** Для разговора вдвоём по умолчанию указано 2 спикера. Для встречи можно задать от 2 до 10 или выбрать «Авто». Разделение голосов тоже работает без интернета после [разовой установки моделей](#разделение-по-говорящим).

**Длинные аудиофайлы можно загружать целиком.** Например, запись встречи не нужно заранее нарезать: приложение автоматически обрабатывает её частями и собирает полную расшифровку. Работа с длинными записями проверена на аудиофайле продолжительностью около 39 минут.

## Возможности

- MP3, WAV, M4A, OGG, FLAC и другие форматы через FFmpeg.
- Длинные записи: обработка всей записи с автоматическим определением речи и пауз.
- Таймкоды относительно начала исходного аудио.
- Разделение реплик по говорящим с выбором числа спикеров или автоматическим определением.
- Флажок «Показывать таймкоды» управляет отображением, копированием и сохранением времени в TXT.
- Две вкладки: исходный текст и очищенный текст с возможностью правок.
- Осторожная очистка заминок, заиканий и отдельных «угу», «ага», «мгм». Удаление коротких реплик можно отключить.
- Прослушивание фрагмента по нажатию на таймкод.
- Повторное распознавание выбранного фрагмента другой моделью.
- Открытие готового TXT и сохранение двух версий.
- Отмена обработки с сохранением завершённых фрагментов в окне.

## Установка

Нужны **Windows**, **Python 3.12 (64 бит)** с Tkinter и **Git**. Проверенная конфигурация использует CPU-версии PyTorch и torchaudio 2.6.0. Приложение не требует видеокарты NVIDIA.

1. Установите [Python 3.12](https://www.python.org/downloads/windows/). В установщике включите добавление Python в PATH и компонент Tcl/Tk.
2. Установите [Git для Windows](https://git-scm.com/downloads/win).
3. Скачайте этот репозиторий через **Code > Download ZIP** и распакуйте его или клонируйте:

   ```powershell
   git clone https://github.com/logser13/gigaam-simple.git
   cd gigaam-simple
   ```

4. Дважды нажмите **Start.cmd**. При первом запуске он создаст `.venv`, скачает проверенную ревизию GigaAM, установит зависимости, подготовит FFmpeg и загрузит модели RNNT и CTC.

Для первоначальной установки нужен интернет и свободное место под зависимости и модели. Веса двух моделей занимают вместе около 892 МБ. Файлы сохраняются в `models/` и не включены в GitHub-репозиторий.

**Полная установка с обеими моделями занимает менее 3 ГБ в проверенной конфигурации Windows с CPU-версиями зависимостей.** Измеренный размер папки программы составляет около 2,6 ГБ: сюда входят зависимости Python в `.venv`, модели CTC и RNNT, FFmpeg и исходники. Это размер установленной программы; аудиозаписи, результаты, временные WAV, кеш установщика и отдельно установленные Python и Git учитываются дополнительно.

Если автоматическая подготовка не завершилась, можно запустить её вручную из папки проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

## Использование

1. Нажмите **Выбрать аудиофайл**, затем **Распознать**.
2. Сравните вкладки **Исходный** и **Очищенный**. Очищенный текст можно редактировать.
3. Нажмите на подчёркнутый таймкод, чтобы прослушать соответствующий фрагмент.
4. При необходимости выберите другую модель и нажмите **Повторить фрагмент**. Ручные правки в других фрагментах сохраняются. Пустой результат повтора не стирает прежний текст.
5. Нажмите **Сохранить обе версии**.

Сохраняются выбранный очищенный TXT и отдельная исходная копия с суффиксом `.original.txt`. Повторное сохранение создаёт `.original-2.txt` и далее, не перезаписывая прежние исходные копии. Очистка сохраняет числа, имена, «да», «нет» и отрицания; она не восстанавливает испорченные слова по догадке.

**Открыть TXT** позволяет очистить уже готовый текст. Для прослушивания TXT с таймкодами дополнительно выберите соответствующий исходный аудиофайл. Новые таймкоды для обычного TXT без времени не создаются.

### Разделение по говорящим

После первого запуска **Start.cmd** один раз запустите **Prepare-speakers.cmd** с интернетом. Он установит [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) и скачает две модели для разделения голосов в `models/speakers/`. Модели занимают около 46 МБ дополнительно к библиотеке. Дальше эта функция работает локально, без аккаунта или ключа API.

Перед распознаванием включите **Разделить по говорящим**. В поле **Спикеров** можно указать от 2 до 10 участников или выбрать **Авто**, если их число неизвестно. По умолчанию выбрано 2. В тексте появятся подписи «Спикер 1», «Спикер 2» и далее. Нумерация начинается заново для каждой записи.

Снимите флажок **Показывать таймкоды**, чтобы скрыть время в обеих вкладках, буфере обмена и новых TXT. Выберите реплику и нажмите **Прослушать**, чтобы услышать её с привязкой к записи. Если сохранить TXT без таймкодов, после повторного открытия этого файла привязка к аудио будет недоступна.

### Как обрабатываются длинные записи

Вы выбираете весь аудиофайл и нажимаете **Распознать**. Программа сама находит речь и паузы, последовательно распознаёт небольшие части и объединяет результат с таймкодами.

**24 секунды - размер внутреннего фрагмента, который передаётся модели, а не ограничение длительности загружаемого файла.** Деление на эти фрагменты выполняется автоматически. Время обработки и объём временных файлов зависят от длительности записи.

## Две модели

| В интерфейсе | Модель | Подготовка |
| --- | --- | --- |
| Альтернативная (по умолчанию) | `v3_e2e_rnnt` | Точнее в среднем на русском |
| Обычная | `v3_e2e_ctc` | Быстрее на проверенной конфигурации |

Если в старой установке есть только CTC, приложение выберет её при запуске. Чтобы добавить RNNT, один раз запустите `Prepare-alternative.cmd` с интернетом. После скачивания обе модели работают локально.

## Ограничения

- Приложение рассчитано на Windows: прослушивание использует `winsound`.
- Это исходники с запуском через Python, отдельного установщика EXE пока нет.
- Имена, числа, отрицания и иностранные термины могут распознаваться ошибочно. Их нужно сверять с записью.
- Таймкоды отмечают начало и конец каждого аудиофрагмента.
- Детектор иногда пропускает очень тихую или короткую речь. При непрерывной речи без пауз возможен разрез внутри слова.
- Очистка коротких реплик может убрать ответ собеседника. Он остаётся в исходной версии; флажок очистки можно отключить.
- Разделение голосов увеличивает время обработки. Похожие голоса и одновременная речь могут привести к ошибкам в подписях. Имена людей программа не определяет.
- Автоматического пересказа нет.
- Скорость зависит от процессора и записи. Приложение не сохраняет несохранённые результаты между запусками.

## Локальные данные

Исходное аудио не изменяется. Временные WAV удаляются после завершения обработки, отмены или обычной ошибки. Исходники приложения не содержат телеметрии или отправки аудио и текста. Ошибки записываются в локальный `app.log`.

Программа проверяет чтение аудио перед загрузкой модели. Если файл не читается, в окне появится короткая подсказка, а подробности декодирования сохранятся в журнале.

Записи, транскрипты, логи, окружение Python, сторонние исходники и скачанные модели исключены через `.gitignore`.

## Проверки

После установки:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s . -p "test_*.py"
.\.venv\Scripts\python.exe check_ui.py
.\.venv\Scripts\python.exe check_review_ui.py
```

Тесты проверяют сохранность аудиофрагментов и таймкодов, очистку текста, отдельное сохранение исходной версии, отмену, повторную обработку и работу интерфейса. Они не измеряют точность модели по эталонной расшифровке. Проверка `check_review_ui.py` использует короткий беззвучный WAV и Windows API воспроизведения.

Для запуска модульных тестов без скачивания GigaAM достаточно Python 3.12 с Tkinter и пакета `imageio-ffmpeg==0.6.0`.
