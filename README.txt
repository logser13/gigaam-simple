GigaAM - локальная расшифровка для Windows, версия 3

Запуск: дважды нажмите Start.cmd.
Можно выбрать длинную запись целиком. Нарезать аудио вручную не требуется.
1. Нажмите «Выбрать аудиофайл».
2. Нажмите «Распознать».
3. Сравните вкладки «Исходный» и «Очищенный».
4. Исправьте очищенный текст при необходимости.
5. Нажмите «Сохранить обе версии»: создаются очищенный TXT и исходная копия.

«Открыть TXT» позволяет очистить готовую расшифровку без аудиофайла.
Исходный файл при этом не меняется. Для TXT без времени новые таймкоды
не создаются: для этого надо повторно распознать исходное аудио.
«Копировать» копирует текст текущей вкладки.
«Очистить заново» пересоздаёт очищенную версию из исходной расшифровки.

Прослушивание и повторная проверка:
1. Нажмите на синий таймкод, чтобы услышать этот фрагмент.
2. «Прослушать» воспроизводит фрагмент, в котором стоит курсор.
3. «Стоп звук» останавливает воспроизведение.
4. Выберите «Обычная» или «Альтернативная» в поле «Модель».
5. «Распознать фрагмент» повторно обрабатывает только этот участок.
Результат обновляется в исходной и очищенной вкладках. Ручные правки
в других фрагментах остаются. Прежние сохранённые TXT не меняются.
Для готового TXT с таймкодами выберите соответствующее исходное аудио
кнопкой «Выбрать аудиофайл». Без аудио прослушивание недоступно.
При отмене повторной проверки предыдущий текст остаётся в окне.

Модель GigaAM v3 e2e CTC работает на процессоре, без облачного API.
«Альтернативная» использует GigaAM v3 e2e RNNT. Качество и скорость
зависят от записи: это другой вариант, а не гарантированное улучшение.
Для первоначального скачивания RNNT запустите Prepare-alternative.cmd.
Модель бесплатна, лицензия MIT. Подписка, ключ API и аккаунт не нужны.
Интернет нужен для установки и первоначального скачивания модели.
После подготовки файлов распознавание работает без интернета.
Приложение не отправляет аудио или текст и не содержит аналитики.

Модель сохраняется в папке models. Временные аудиофайлы удаляются
после обработки, отмены или обычной ошибки. Исходный файл не меняется.
Текст сохраняется только по кнопке «Сохранить обе версии».
Исходная копия получает суффикс .original.txt. При повторном сохранении
создаётся новая копия .original-2.txt и далее, предыдущая не перезаписывается.

Для первого знакомства удобно взять короткую запись отчётливой русской речи.
Длительные записи встреч можно загружать целиком.
Локальный Silero VAD определяет речь и паузы и пропускает длинную тишину.
Внутри программы модель получает фрагменты до 24 секунд, преимущественно
разделённые по паузам. Это размер внутреннего фрагмента, а не ограничение
длительности загружаемого файла. Нарезка и объединение полной расшифровки
выполняются автоматически.
При непрерывной речи без пауз всё ещё возможен разрез внутри слова.
Таймкоды показывают границы аудиофрагментов относительно начала записи.
Это не точное время каждого слова и не определение смены говорящего.
Очень тихую или короткую речь детектор иногда может пропустить.

Очистка выполняется локальными правилами: убирает «э-э», «а-а» и похожие
звуки заминки, а также очевидные заикания вроде «я-я» и «мы мы».
По умолчанию также убираются отдельные «угу», «ага», «мгм» и их варианты
через дефис. Отключить это можно флажком в очищенной вкладке.
«Да», «нет» и «не» не удаляются. Короткая реплика иногда является
ответом: для проверки она остаётся в исходной вкладке и в записи.
Она не придумывает испорченные слова, не исправляет числа, имена,
термины и отрицания. Исходная расшифровка остаётся доступной.
Русские модели иногда записывают иностранные слова кириллицей или
путают их с похожими словами. Названия, аббревиатуры и термины
проверяйте прослушиванием, особенно если они влияют на смысл.
Разделение говорящих и создание пересказа в этот тест не входят.
«Остановить» завершает текущий фрагмент, готовый текст остаётся.
Скорость зависит от процессора, длительности записи и её качества.
Точность не гарантирована: имена, числа и важные детали проверяйте.

Это тестовая версия в отдельной папке, не установщик EXE.
Нужны Python 3.12 для Windows (64 бит, с Tkinter и добавлением в PATH)
и Git. При первом запуске Start.cmd автоматически запускает setup.ps1.
Для повторной установки зависимостей: setup.ps1.
Ошибки распознавания записываются в app.log, без аудио и транскриптов.
